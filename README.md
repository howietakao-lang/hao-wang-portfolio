# HAO WANG — Portfolio Prototype V2

## What changed
- Explicit three-language switch: 中文 / 日本語 / EN (Chinese, Japanese, English), including project cards, detail narratives, project gallery labels, and basic interface copy. The chosen language is saved locally when available.
- Cultural Fermentation now uses images from the user's actual 46-slide PPT presentation (48 exported source-page images) prominently in the project gallery, including final installation photographs, design process, light testing, tea vessel, shoji projection, and spatial studies. The complete slide archive remains browsable.
- Independent animation stills and process images from the uploaded PDF remain integrated.
- Three categories: Independent Animation / Independent Projects / Internships.
- Videos remain to be added when supplied.

## View locally
Unzip the entire folder and open `index.html`. For best results, open a terminal in the folder and run `python3 -m http.server 8000`, then visit http://localhost:8000. Keep the `assets` folder beside `index.html`.

## Publishing cautions
- Homepage flower/metal reference remains a temporary screenshot from the user-supplied design reference, not an original sculpture; replace before public release.
- The PPT includes inspirational/reference imagery (potentially third-party) alongside project documentation. Review rights and attribution before public publication.
- Internship descriptions are public-safe summaries; private materials, confidential data, and user information are not published.
- Graduate film and internship images may be placeholders pending original approved materials.
